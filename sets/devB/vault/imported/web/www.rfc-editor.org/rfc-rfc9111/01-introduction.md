RFC 9111 HTTP Caching June 2022 Fielding, et al. Standards Track \[Page]

## Abstract

The Hypertext Transfer Protocol (HTTP) is a stateless application-level protocol for distributed, collaborative, hypertext information systems. This document defines HTTP caches and the associated header fields that control cache behavior or indicate cacheable response messages.[¶](#section-abstract-1)

This document obsoletes RFC 7234.[¶](#section-abstract-2)
